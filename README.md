# Custom-BLDC-Motor-Controller-ESC

## Overview:
A custom 3-phase Electronic Speed Controller (ESC) developed for AUV thruster control, designed around the STM32G071KBT6 microcontroller. The controller integrates a three-phase MOSFET power stage, gate-driver circuitry, six-step BLDC commutation, current and voltage sensing, and communication interfaces on a compact custom PCB.
---
## Key Features:

* 3-phase BLDC motor control using a **six-MOSFET half-bridge inverter**
* **Six-step commutation** for BLDC motor operation
* FD6288Q gate driver with **high-side and low-side gate driving**
* Bootstrap circuitry for high-side MOSFET operation
* Shunt-based **current sensing using INA180**
* Battery-voltage and three-phase voltage sensing through ADC
* Dedicated 3.3 V regulated supply for control electronics
* SWD interface for firmware programming and debugging
---
## Protocols & Configurations:

* **PWM:** Six PWM outputs generated by the STM32 for MOSFET gate control
* **UART/USART:** Used for firmware flashing, debugging, and controller communication
* **SWD:** Used for STM32 programming and hardware debugging
* **ADC:** Used for battery voltage, current, and phase-voltage measurements
* **STM32CubeMX:** Used for pin mapping, pin muxing, GPIO configuration, timer/PWM setup, ADC configuration, and peripheral assignment

## Applications:

The ESC is designed primarily for **AUV and underwater thruster applications**, where reliable three-phase BLDC motor control is required. Its architecture can also be adapted for **robotics, drones, electric propulsion systems, and other custom BLDC motor-control applications**.

## Tools & Technologies:

**Altium Designer** — schematic design and PCB development
**STM32CubeMX** — MCU configuration, pin muxing, timers, ADC and peripheral setup
**QSPICE** — MOSFET switching and power-electronics simulation
**STM32G071KBT6** — motor-control MCU
**FD6288Q** — 3-phase MOSFET gate driver
**INA180** — current-sense amplifier

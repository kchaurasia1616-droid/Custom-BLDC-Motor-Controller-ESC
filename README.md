# Custom-BLDC-Motor-Controller-ESC

Overview:
A custom 3-phase Electronic Speed Controller (ESC) developed for AUV thruster control, designed around the STM32G071KBT6 microcontroller. The controller integrates a three-phase MOSFET power stage, gate-driver circuitry, six-step BLDC commutation, current and voltage sensing, and communication interfaces on a compact custom PCB.
